# 星环守卫 · Orbit Guard

一个极简、离线的 Android 放置塔防小游戏。打开即自动开火，赚金币，升级，再守一轮。

## 下载

前往 [Releases](https://github.com/The8ravo/orbit-guard-lite/releases/latest) 下载 `orbit-guard-v1.0.0.apk`，在 Android 手机上打开安装。私有仓库需要登录仓库拥有者的 GitHub 账号才能下载。

## 玩法

- 只有 **普通敌人** 和 **每 10 波一个首领**。
- 只有 **一种金币** 和 **攻击、攻速、生命** 三项永久升级。
- 防御塔自动攻击，支持暂停和 **1× / 2× / 4×** 速度。
- 点击右上角金币打开 **金币修改器**：输入任意 `0–999999999999` 的整数，或点击快捷加币，再保存。
- 战败后点击「重新挑战」；金币和升级保留。
- 自动保存当前战斗，离开应用后暂停，回来继续。不计算离线收益。

没有充值、广告、登录、联网、抽卡、装备、科技树或任务系统。

## 设计与数值

使用原创名称、几何图形和界面，不包含原游戏素材或代码。

参考 The Tower 社区资料中的首领设定：每 10 波出现、20 倍基础生命、0.3 倍基础移速。波次成长、金币收入和升级价格为适合短局游戏的自定义数值，**并非对原游戏数值的精确复刻**。公式与来源见 [数值说明](docs/enemy-balance.md)。

## 源码

| 路径 | 内容 |
| --- | --- |
| `web/engine.js` | 独立的战斗、升级、存档模拟 |
| `web/app.js` | Canvas 绘制与界面交互 |
| `web/index.html`, `web/style.css` | 单屏手机界面 |
| `android/` | 原生 Android WebView 容器 |
| `tests/` | 战斗与存档回归测试 |
| `tools/` | 本地预览及 APK 构建脚本 |

### 本地预览

安装 Node.js，然后运行：

```shell
node tools/serve.cjs
```

浏览器访问 `http://127.0.0.1:4173`。

### 测试

```shell
node --test tests/engine.test.cjs tests/app-state.test.cjs
```

覆盖升级扣款、金币边界、战斗奖励、首领波次、暂停/倍速、存档恢复和双存储回退。手机浏览器额外检查修改器、重开、升级和小屏布局。

### Android 构建

构建方式与开发签名说明见 [Android 构建说明](docs/android-build.md)。SDK、JDK、构建缓存和签名密钥不提交到仓库。

## 存档

存档保存在本机应用数据内。卸载或清除应用数据会删除进度；新安装从零开始。安装相同签名的更新可保留存档。
